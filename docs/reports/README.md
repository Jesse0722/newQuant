# 行情质量与修复证据归档

本目录保存质量摘要、冻结代码范围、原始来源快照、已核对差异计划和批次执行记录。历史报告描述对应日期的库状态，不代表当前全市场行情已恢复或评分已放行。

完整 T02 质量 JSON 使用同名 `.json.gz` 无损归档，避免重复的大型代码清单占据文本 diff。未压缩 JSON 留在本地并由 Git 忽略，不会被删除。报告中的同名 JSON 链接可在解压后使用，例如从仓库根目录运行：

```bash
gzip -d -k docs/reports/2026-11-04-market-data-quality.json.gz
```

该命令保留压缩归档；若本地原 JSON 已存在，应直接使用原文件，不要覆盖。归档采用 `gzip -n -9`，解压字节与归档前 JSON 完全一致。原始来源、差异计划及其核对哈希保持不变，CLI 应用仍使用未压缩的原计划 JSON。

业务数据库、完整数据库备份及凭据不进入本目录或 Git。执行记录中的私有备份路径仅供原操作环境定位；不能把市场质量 JSON 当成可恢复业务库的备份。修复与回滚步骤见[操作手册](../daily-quote-repair.md)。
