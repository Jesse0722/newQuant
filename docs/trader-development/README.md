## 1. 课题愿景

通过持续学习、量化研究、交易训练与复盘，逐步形成专业化的A股交易能力。

以 `newQuant` 为研究和验证平台，建立完整的：

市场认知 → 市场环境判断 → 策略选择 → 交易计划 → 风险控制 → 执行记录 → 绩效评估 → 策略改进

本课题不以短期盈利或立即全职交易为目标。

长期目标是建立具有可验证统计优势、能够控制风险、可以持续迭代的个人交易体系。

## 2. 基本原则

1. 生存优先于盈利，风险控制优先于收益最大化。
2. 先判断市场环境，再评估策略适配性，最后寻找个股机会。
3. 区分事实、假设、回测结果和个人判断。
4. 不把历史信号收益直接等同于实际可执行收益。
5. 每次策略修改必须说明假设、证据、测试方法及验收标准。
6. 不根据少量成功案例判断策略有效。
7. 不因为学习时间达到预定期限而自动升级。
8. 不将“已提出”“已开发”“已测试”“已验证有效”混为一谈。
9. 不以回本压力或短期收益目标推动交易。
10. 优先复用现有 `newQuant` 能力，避免重复开发。

## 3. 长期培养路线

### S1：交易基础与研究工具

目标：掌握A股交易制度、技术指标、市场结构、基础统计与研究工具。

主要能力：
- 趋势、成交量、波动率和市场宽度分析
- 基础策略设计
- 行情数据获取与指标计算
- 历史信号识别
- 基础交易复盘

当前评估：已有较多研究和工程基础，但不代表所有知识点均已通过考核。

### S2：策略验证与交易体系重建

目标：证明策略在什么市场环境下可能有效，识别其失效边界。

主要任务：
- 审计现有回测口径
- 建立市场环境分类体系
- 研究策略在不同市场环境下的条件绩效
- 建立可执行的交易成本、成交和退出模拟
- 建立组合风险与最大回撤分析
- 形成交易手册V1

毕业要求：
- 策略定义完整且可复现
- 无明显前视偏差
- 数据覆盖范围和局限清楚
- 已完成分市场环境回测
- 已完成样本外验证
- 有明确的交易许可、风险预算与退出规则

当前阶段：**S2，正在进行。**

### S3：模拟执行与交易纪律

目标：将经过研究的策略转化为可执行的交易流程。

主要任务：
- 每日盘前交易计划
- 模拟交易与成交记录
- 计划与实际执行差异分析
- 仓位与组合风险管理
- 周度、月度复盘
- 识别情绪化交易和规则偏离

毕业要求：
- 连续、完整的模拟交易记录
- 规则执行率达到事先确定的标准
- 能够解释主要盈利和亏损来源
- 无未解决的重大风控违规
- 策略绩效通过预设的统计与风险审查

### S4：小规模实盘验证

目标：在严格风险预算下验证真实执行能力。

进入前提：S3通过验收，且个人财务和风险承受能力允许。

主要任务：
- 小规模资金验证
- 记录真实成交成本与滑点
- 监控组合回撤和风险暴露
- 对比模拟交易与真实执行结果
- 建立暂停交易与恢复交易规则

毕业要求：
- 有充分的实盘执行证据
- 风险约束得到执行
- 收益与风险表现可解释
- 未出现未解决的重大纪律问题

### S5：专业化交易运营

目标：形成长期、稳定、可持续的交易研究与管理机制。

主要任务：
- 策略组合与相关性管理
- 市场环境变化监测
- 定期策略失效审查
- 年度绩效与风险评估
- 资金管理和生活现金流规划
- 持续学习与研究迭代

是否全职交易属于独立的职业与财务决策，不由单一策略的短期收益决定。

## 4. 短期、中期、长期目标

### 短期：0–3个月

重点：从策略开发转向策略验证。

交付：
- 现有策略与回测能力审计
- 市场环境分类V1
- 主升浪策略条件绩效报告
- 风险与退出规则V1
- 交易研究日志

### 中期：3–12个月

重点：从策略验证转向稳定执行。

交付：
- 样本外验证报告
- 模拟交易记录
- 组合级风险管理
- 月度绩效归因
- 规则执行与纪律评估

### 长期：1–3年及以上

重点：形成专业化交易能力。

交付：
- 持续维护的策略研究体系
- 跨市场环境的风险管理机制
- 长期交易绩效档案
- 策略迭代和失效处理机制
- 职业化可行性评估

所有期限均为规划参考，实际晋级以验收证据为准。

## 5. 当前能力与问题基线

### 已确认的工程基础

根据 `newQuant` master 分支静态代码审查：

- 存在主升浪趋势分析与评分服务
- 存在策略扫描能力
- 存在历史信号回测服务
- 存在分阶段、分评分区间的信号收益汇总
- 存在观察池、交易计划与复盘相关工作流设计

上述结论仅表示仓库中存在相关实现，不代表功能已在当前环境成功运行或交易策略已被证明有效。

### 待验证问题

**H1：市场环境适配性**

主升浪策略在下跌或高波动环境中的条件期望收益可能显著下降。

**H2：回测可信度**

现有信号日收盘价与实际可成交价格之间可能存在收益偏差。

**H3：风险控制**

现有研究尚未充分证明仓位、退出、交易成本和组合回撤控制的有效性。

**H4：交易执行**

个人真实交易是否稳定遵守规则，尚缺少完整的可核验记录。

以上均为研究假设，不作为已经确认的事实。

## 6. 当前研究重点

**核心问题：主升浪趋势策略究竟适合什么样的A股市场环境？**

研究顺序：

1. 验证回测结果是否可信。
2. 建立历史市场环境标签。
3. 测量策略在不同环境下的表现。
4. 比较有无市场过滤器的净收益与风险。
5. 形成交易许可与仓位管理规则。
6. 通过样本外数据检验规则稳定性。

在完成上述研究前，暂不把新增买点指标作为优先工作。

## 7. 第一阶段执行计划：30天

### 第1周：回测可信度审计

目标：区分信号统计与真实交易绩效。

任务：
- 审查信号生成与成交时间
- 审查未来数据使用风险
- 审查价格复权与数据覆盖
- 检查交易成本、涨跌停、停牌约束
- 检查最大回撤等指标定义
- 建立测试案例

交付：回测可信度审计报告。

### 第2周：市场环境识别

目标：建立可回溯的市场环境分类。

研究内容：
- 指数趋势
- 市场宽度
- 成交额变化
- 波动率
- 新高与新低股票数量
- 板块趋势扩张和收缩

交付：市场环境分类规则V1。

### 第3周：策略适配性验证

目标：验证市场环境对主升浪策略的影响。

研究内容：
- 不同环境下的独立交易数量
- 净期望R
- 胜率与盈亏比
- 假突破率
- 最大回撤
- 交易机会成本
- 环境过滤器与原始策略对照

交付：分市场环境绩效报告。

### 第4周：交易体系V1

目标：形成可执行的交易决策规则。

研究内容：
- 允许交易的市场环境
- 降低风险的触发条件
- 暂停新开仓的条件
- 单笔风险预算
- 组合风险限制
- 退出和策略失效机制

交付：交易手册V1与下一阶段计划。

## 8. 任务与证据管理

每项任务必须具有：

- 任务ID
- 所属培养阶段
- 研究问题
- 当前假设
- 相关代码或数据
- 实验方法
- 验收标准
- 研究结论
- 风险与局限
- 下一步行动

任务状态统一为：

`未开始 / 进行中 / 待验证 / 已完成 / 暂停`

状态规则：

- 已提出不等于已完成
- 已编码不等于已测试
- 测试通过不等于策略有效
- 回测盈利不等于实盘可盈利
- 缺少证据时保持“待验证”

## 9. 学习与复盘机制

### 每日

- 记录市场状态
- 观察趋势机会与风险
- 完成一个小型学习或验证任务
- 记录新的疑问与发现

### 每周

- 回顾已完成任务
- 审核实验结果
- 识别认知偏差与执行偏差
- 更新问题清单
- 确定下一周唯一优先事项

### 每月

- 评估培养阶段
- 审核策略有效性证据
- 复核风险控制能力
- 形成月度学习与交易研究报告
- 决定是否达到下一阶段的进入条件

## 10. AI协作约定

AI助手承担以下职责：

- 协助学习交易理论
- 审查策略逻辑与代码
- 设计可验证实验
- 分析回测结果
- 指出证据不足和研究偏差
- 整理学习与研究记录
- 协助制定下一步任务

AI助手不得：

- 将未经验证的研究假设表述为事实
- 将建议过的任务视为已经完成
- 编造回测或实盘绩效
- 用单一市场行情推断策略长期有效性
- 在没有明确授权时修改交易代码或提交交易指令
