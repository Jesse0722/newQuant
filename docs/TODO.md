当前应先补齐 PostgreSQL 迁移、恢复测试基线并建立全市场数据质量闭环，再推进市场状态评分。GraphRAG、主升浪回测、消息证据 Agent 和通知中心一期已有实现，剩余工作主要是可靠性、追溯和验收补齐。

## 使用规则

- **P0**：对应场景的前置门槛；不代表当前线上已经发生故障。
- **P1**：近期修复或验收补齐。
- **P2**：后续增强，按依赖安排。
- **P3**：可选规划，需产品决策后立项。
- **已确认缺口**依据当前代码；**待验证**需要实际数据库、运行服务或外部权限；**规划**不能算现有功能故障。
- 下列编号为可独立指派的任务包，包内仍需按最小可交付范围拆分。不得一次性混合修改数据库、评分、采集和前端。
