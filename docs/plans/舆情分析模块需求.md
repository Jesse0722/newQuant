# 消息中心：题材与个股机会模块 PRD

> 状态：MVP 已实现，X 采集接入中
> 日期：2026-05-14
> 范围：新增“消息中心”页面，让用户每天打开网页即可看到今日题材、个股机会，并能进入现有观察池/买点雷达工作流。

## 1. 背景

当前系统已经形成“观察池 -> 买点雷达 -> 买点提醒 -> 交易计划 -> 复盘”的主工作流。缺口在于：用户每天还需要从 Twitter/X、雪球、淘股吧、小红书等渠道人工浏览题材信息，再判断哪些主题或个股值得加入观察池。

本模块的目标不是直接给出买卖信号，而是做“题材发现与机会提示”：把每日市场讨论的 AI 产业题材、个股映射和风险拥挤度整理到系统首页级入口里，让用户快速完成“今天看什么”的判断。

## 2. 产品定位

### 2.1 一句话

消息中心每日展示“今日题材”和“个股机会”，帮助用户把舆情线索转化为观察池关注对象。

### 2.2 不做什么

- 不做自动交易信号。
- 不做买卖点替代，买点仍由现有买点雷达判断。
- MVP 不直接承诺全平台自动采集稳定可用。
- MVP 不做复杂回测和收益归因。

## 3. 用户目标

用户每天打开系统后，希望在一个页面完成：

1. 看到今日最值得关注的 AI 产业题材。
2. 看到每个题材对应的个股机会。
3. 理解机会背后的逻辑、来源、催化剂和风险。
4. 判断题材处于早期、扩散期、高潮期还是退潮期。
5. 一键把个股加入核心关注，后续交给买点雷达跟踪。

## 4. 平台角色

| 平台 | 角色 | MVP 使用方式 |
|---|---|---|
| Twitter/X | 前沿产业叙事源 | 已接入 recent search MVP，优先关注 AI、半导体、算力、电力链 |
| 雪球 | A股映射与逻辑补强 | 后续采集器接入，用于识别 A股产业链映射 |
| 淘股吧 | 短线资金情绪 | 后续采集器接入，用于判断题材情绪周期 |
| 小红书 | 大众扩散与拥挤度 | 后续只采集指数变化，不作为深度文本源 |

## 5. MVP 功能范围

### 5.1 今日题材列表

展示字段：

- 题材名称
- 生命周期：早期 / 扩散 / 高潮 / 退潮
- 热度分
- 可信度分
- 拥挤度分
- 情绪：正向 / 中性 / 负向
- 摘要
- 来源平台
- 标签

### 5.2 个股机会列表

展示字段：

- 股票代码
- 股票名称
- 关联题材
- 机会评分
- 热度分
- 可信度分
- 风险分
- 建议动作：关注 / 加入观察 / 风险观察
- 机会逻辑
- 催化剂
- 风险
- 来源平台

### 5.3 关键操作

- 刷新今日消息。
- 只看高分机会。
- 按题材筛选个股机会。
- 跳转股票详情。
- 将个股加入核心关注。

### 5.4 数据输入

MVP 先提供稳定的数据承载与展示接口：

- 系统内置 AI 产业种子机会，用于保证第一版页面每日可用。
- 后端提供原始消息导入接口，供外部渠道、手动导入、文件导入或 webhook 写入。
- X recent search 先接入，输出原始消息、题材和 A 股候选机会。
- 后续采集器可独立接入雪球、淘股吧、小红书，不影响页面与核心工作流。

## 5.5 X MVP 种子池

种子池随代码版本化，路径为 `backend/app/seeds/`：

- `message_keywords.csv`：AI 产业关键词。
- `message_x_accounts.csv`：X 重点账号池。
- `message_x_stock_mappings.csv`：海外 ticker / 产业词到 A 股候选映射。

第一版重点主题：

| 主题 | 优先级 |
|---|---|
| AI算力 | S |
| 存储芯片 / HBM | S |
| 光模块 / CPO | S |
| 铜连接 | S |
| 液冷 | A |
| AI电力 | A |
| PCB | A |
| AI服务器 | A |
| ASIC | A |
| 机器人 | B |
| AI应用 | B |

X 采集边界：

- 只采集公开文本帖子和公开互动指标。
- 默认使用高优先级关键词，小批量 recent search。
- 不做实时流、不做图片/OCR、不做短视频理解、不做自动互动。
- 采集结果进入消息中心，不直接生成交易指令。

## 6. 验收标准

1. 用户可在侧边栏进入“消息中心”。
2. 页面默认展示今日题材和今日个股机会。
3. 题材列表包含热度、可信度、拥挤度和生命周期。
4. 个股机会列表包含评分、逻辑、催化剂、风险和来源。
5. 至少 5 条今日个股机会可见。
6. 对有股票代码的机会，可以跳转到股票详情。
7. 对有股票代码的机会，可以加入核心关注。
8. 后端 API 有单元测试覆盖今日摘要和机会写入。
9. 前端有 Playwright 测试覆盖消息中心展示与筛选。
