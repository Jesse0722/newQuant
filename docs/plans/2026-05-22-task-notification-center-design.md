# 任务消息中心设计文档

## 背景

系统里已经有多类异步或耗时操作：AI 深度分析、AI 智能选股、股票池同步、数据采集、买点扫描、策略回测等。当前多数页面采用页面内 loading、轮询和 toast 提示，用户离开页面后容易丢失结果，也无法回看失败原因。

本设计新增顶部“任务消息中心”，定位为全局任务收件箱：任务提交后用户可以继续操作，完成或失败后在顶部提示，并在消息中心保留可点击记录。

注意：现有侧边栏“题材挖掘”页面原曾命名为消息中心，负责题材与舆情机会；本设计中的消息中心指顶部通知入口，不替代题材挖掘页面。

## 目标

- 顶部固定入口展示未读任务消息数量。
- 异步任务提交后进入消息中心，保留运行中、成功、失败状态。
- 任务完成后弹出顶部通知，点击可跳转到结果页面或来源页面。
- 用户可标记已读、清理已读，避免消息堆积。
- 第一阶段不引入新消息表，先复用现有后台任务状态和浏览器本地持久化，降低改造成本。

## 任务纳入原则

适合放入任务消息中心的任务需要同时满足：

- 执行耗时或依赖外部接口，用户不应被迫停留等待。
- 完成后有结果可看，或失败后需要明确原因。
- 用户离开当前页面后仍然需要被提醒。
- 状态可被轮询或可由后端任务系统追踪。

不适合纳入的任务：

- 保存备注、切换关注、删除记录等即时操作。
- 页面加载类请求。
- 没有结果查看价值的轻量按钮动作。

## 分期范围

### 第一期

第一期聚焦最高频、最容易让用户等待的任务：

- 股票 AI 深度分析
  - 来源：观察池、股票详情页。
  - 动作：提交任务、顶部提醒、点击查看股票详情。
- AI 智能选股
  - 来源：策略选股页。
  - 动作：完成后提醒，点击回到策略选股页查看结果。
- 股票池同步
  - 来源：观察池。
  - 动作：完成后提醒，点击回到观察池。
- 买点提醒触发
  - 来源：买点雷达/监控扫描。
  - 动作：进入消息中心作为待处理业务提醒，点击查看买点提醒页。

### 第二期

第二期纳入数据和验证类任务，其中策略回溯/回测明确放在第二期：

- 策略回溯 / 策略回测。
- 题材与 X 舆情采集。
- 涨停池采集。
- 盘后最新 K 线补齐。
- 定时任务执行结果。
- 数据源异常、Token 失效、接口额度不足。

### 第三期

- 批量 AI 分析核心关注池。
- 策略优化建议生成。
- 自动监控规则触发汇总。
- 组合级日报、周报生成。

## 交互设计

顶部栏右侧新增铃铛入口：

- 未读数：只统计未读消息，包括运行中、成功、失败。
- 点击铃铛：打开 Popover 列表。
- 列表项展示：标题、描述、状态标签、更新时间。
- 列表项动作：点击标记已读，并跳转到对应页面。
- 顶部动作：全部已读、清理已读。

消息状态：

- `running`：任务已提交或执行中。
- `success`：任务完成并有结果。
- `error`：任务失败或状态查询失败。

文案规范：

- 标题说明“对象 + 任务 + 状态”，例如“浪潮信息 深度分析完成”。
- 描述说明结果摘要或下一步动作，例如“点击查看最新分析结果”。
- 失败消息优先展示后端返回的失败原因。

## 技术方案

第一阶段采用轻量实现：

- 后端复用 `app.tasks.background.task_registry`。
- 对需要纳入消息中心的任务补充异步提交接口和任务状态查询接口。
- 前端新增 `notificationCenter` 服务：
  - 使用 `localStorage` 保存最近 80 条消息。
  - 使用浏览器事件同步页面内状态。
  - 顶部布局组件统一轮询运行中任务。
- 任务结果仍由原业务页面负责渲染，消息中心只负责提醒和跳转。

后续演进：

- 新增后端 `app_notification` 表，支持跨浏览器、跨设备、服务端定时任务消息。
- 后端统一任务事件：submitted、progress、completed、failed。
- 前端改为 SSE 或 WebSocket 推送，减少轮询。

## API 约定

第一阶段各业务可先提供独立任务状态接口，响应字段保持一致：

```json
{
  "task_id": "...",
  "type": "stock_ai_analysis",
  "status": "running|completed|failed",
  "progress": 0.5,
  "message": "执行中...",
  "result": {},
  "created_at": "2026-05-22T10:00:00Z"
}
```

前端消息对象：

```json
{
  "id": "stock-ai-analysis:<task_id>",
  "kind": "stock_ai_analysis",
  "status": "running",
  "title": "浪潮信息 深度分析中",
  "description": "任务已提交，完成后会在顶部消息中心提醒",
  "read": false,
  "taskId": "...",
  "link": "/stocks/000977.SZ",
  "meta": {}
}
```

## 验收标准

- 提交股票 AI 深度分析后页面不阻塞。
- 顶部铃铛立即出现运行中消息。
- 任务完成后顶部弹出通知，消息中心状态变为已完成。
- 点击消息可跳转对应股票详情页。
- 第一阶段不包含策略回溯/策略回测通知。
