# 五日均线不破（涨停回调）— 策略说明与实现

> 策略 ID：`ma5_hold_pullback`  
> 代码：`backend/app/services/limit_up_tactics.py` → `analyze_ma5_hold_pullback`  
> 回测：`backend/scripts/backtest_ma5_hold_pullback.py`（近 30 交易日涨停股 universe）

---

## 一、业务含义

在**最近一次涨停（与现有战法一致，由窗口内回溯得到）**之后，在 **第 3～5 个交易日**内寻找**缩量回调、未有效破位**的企稳买点；与「次日缩量」「回踩 5 日线」等战法并列，供买点雷达选择。

---

## 二、量化口径（实现对照）

| 维度 | 要求 | 代码实现要点 |
|------|------|----------------|
| 幅度 | 回调相对**首板涨停收盘**约 **8%～15%** | 取涨停次日至信号日区间内**最低价** `min_low`，`pullback_pct = (lu_close - min_low) / lu_close * 100`，要求落在 `[8, 15]` |
| 时间 | **3～5** 个交易日 | `days_since = latest_idx - limit_up_idx`，要求 `3 <= days_since <= 5` |
| 量能 | 缩量，**≤ 首板日成交量 50%** | `latest["vol"] <= lu_vol * 0.5` |
| 支撑 | 不破**首板最低价**，且收盘**站稳 5 日均线** | `low >= lu_low * 0.99` 且 `close >= ma5 * 0.995`（无 MA5 时退化为仅首板低） |
| 企稳 / 均线 | 满足其一即可 | **缩量十字星** / **阳包阴** / **两日收盘近似持平** / **缩量回踩 5 或 10 日线（±2%）** |
| 公共前置 | 与其它战法共用 | `common_pre_filter`：非一字、窗口内未破涨停低价（1% 容差）、换手与高位过滤等 |

**说明**：若首板实体较满，`lu_low` 接近 `lu_close`，则「8%～15%」与「不破首板最低价」可能难以同时满足，信号会偏少，属预期行为。

---

## 三、触发档位（与其它战法一致）

- 使用统一加权评分 `_build_signal`：**全部 core 条件满足**且总分 ≥80 → `triggered`；略低档位为 `approaching` / `tracking` 等。

---

## 四、回测方法

- `strategy_backtest.run_strategy_backtest(..., use_limit_up_universe=True, universe_from_local_db=True)`：在 `trade_date_from`～`trade_date_to` 内用 `fetch_limit_up_stocks_from_db`（本地 `daily_quote`，不访问外网）得到涨停股代码集合，再逐日滚动检测 `triggered`，统计 T+1 / T+3 / T+5 收益。若设 `universe_from_local_db=False` 则改为逐日 API `fetch_limit_up_stocks_in_range`（较慢、依赖网络）。
- 脚本：`backend/scripts/backtest_ma5_hold_pullback.py` 默认取**最近 30 个交易日**为日期窗。

**数据前提**：本地需已同步相关标的日线（否则该股会被跳过）。

---

## 五、Review 摘要

1. **首板定义**：与现有涨停战法一致，取 `snap` 内**最近**一次涨停索引，非「年度首板」语义；若多段涨停，锚定为离信号最近的一段。  
2. **8%～15%**：对区间**最低价**度量，不是仅看当日收盘。  
3. **企稳与均线**：实现为「四类信号之一」满足 `stabilize_or_ma`，避免与量能条件重复计数（十字星/回踩均线内含缩量约束）。  
4. **回测 universe**：来自区间涨停扫描，与观察池无关，便于全样本统计。

---

## 六、命令示例

```bash
cd backend && ./venv/bin/python scripts/backtest_ma5_hold_pullback.py
```

买点雷达中选择策略 **「五日均线不破」**（`ma5_hold_pullback`）即可与线上扫描逻辑一致。

---

## 七、回测结果（示例环境）

在 **本地 `daily_quote` 已覆盖近 30 个交易日** 的前提下，使用 `fetch_limit_up_stocks_from_db` 得到 **71** 只区间内曾涨停标的，运行 `scripts/backtest_ma5_hold_pullback.py` 得到：

- **total_signals**: 0  
- **win_rate_1d / 3d / 5d**、**avg_return_*** 均为 0（无触发样本）

**说明**：本策略同时要求 **公共前置**（未破涨停低价、换手与高位过滤等）、**8%～15% 回调深度**、**当日量能 ≤ 首板 50%** 以及 **企稳/均线确认**，在样本池内全部满足并达到 `triggered` 档位的情形较少；若需提高命中率，需在业务上放宽某一档条件（或延长本地日线历史窗口后重跑）。外网 API 版 universe（`universe_from_local_db=False`）仅改变涨停股名单来源，不改变上述判定逻辑。
