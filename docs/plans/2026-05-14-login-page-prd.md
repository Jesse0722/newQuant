# 登录页 PRD

> 日期：2026-05-14  
> 状态：MVP 定稿  
> 范围：新增专业登录页与前端会话保护；不做注册，不接入多用户权限。

## 1. 背景

当前系统已经具备仪表盘、观察池、买点雷达、消息中心、交易计划等核心雏形，但打开网页后直接进入业务系统。为了让系统更像一个完整的专业工作台，需要新增登录页作为入口。

## 2. 目标

用户打开网页后先进入登录页，输入预设账号即可进入星枢 Quant 工作台。

默认账号：

```text
用户名：admin
密码：预设密码，不在界面展示
```

## 3. 产品边界

### 做

- 独立登录页。
- 登录成功后进入仪表盘。
- 未登录访问业务页面时跳转登录页。
- 已登录访问登录页时跳转仪表盘。
- 支持退出登录。
- 登录页视觉风格专业、科技感、符合当前深色量化系统。

### 不做

- 不做注册。
- 不做忘记密码。
- 不做多角色权限。
- 不做服务端账号体系。
- 不做真实安全加密认证。

## 4. 页面设计

### 登录页核心元素

- 品牌名：星枢 Quant
- 副标题：AI Quant Workflow
- 系统定位文案：策略、舆情、买点、计划一体化工作台
- 登录表单：用户名、密码、登录按钮
- 登录提示：仅本地 MVP 使用，不在界面展示默认密码
- 视觉元素：行情网格、指标卡、扫描线、霓虹描边

### 成功/失败反馈

- 账号密码正确：进入 `/`
- 账号密码错误：提示“账号或密码错误”
- 空表单：表单校验提示

## 5. 验收标准

1. 打开 `/` 且未登录时跳转 `/login`。
2. `/login` 页面展示专业登录界面。
3. 输入预设账号后进入仪表盘。
4. 输入错误账号密码时无法进入系统，并展示错误提示。
5. 登录状态刷新页面后保持。
6. 侧边栏提供退出登录入口。
7. Playwright 覆盖登录成功与失败。
