# 涨停回调买入策略 — 实施方案（已实施）

> 2026-03 实施完成。实现「涨停回调买入法」：每日筛选涨停股加入专用观察池并打标签，监控回踩买点，触发后自动加入核心观察池。

---

## 一、策略逻辑与数据流

- **每日任务**：直接调用 Tushare 获取涨停股 → 加入涨停股票观察池 → 打涨停日期标签 → 自动同步 60 日 K 线
- **监控扫描**：扫描涨停池，按配置的买点规则检测
- **买点触发**：创建 Alert 后，自动将股票加入配置的目标池（核心观察池）

---

## 二、买点策略（监控模板）

| 模板 ID | 名称 | 说明 | 参数 |
|---------|------|------|------|
| ma_support | 均线支撑 | 收盘价回踩 MA(N) 附近（±2%） | n（默认 10） |
| limit_up_price_support | 涨停板价支撑 | 收盘价回踩涨停板价附近 | tolerance（默认 0.03） |
| days_since_limit_up | 涨停后时间窗口 | 涨停后 N~M 个交易日内有效 | min_days, max_days（默认 3, 15） |
| fibonacci_retrace | 黄金分割回调 | 涨停后最高点回调至 0.382/0.5 附近 | level, tolerance |
| volume_shrink | 缩量回调 | 价格下跌且成交量萎缩 | ratio（默认 0.7） |
| price_threshold | 价格阈值 | 跌破基准价 × 比例（涨停池自动用涨停价作基准） | ratio（默认 0.95） |

**推荐组合**：
- A：ma_support(10) AND volume_shrink(0.7) — 回踩 MA10 且缩量
- B：limit_up_price_support(0.03) AND days_since_limit_up(3,15) — 涨停价支撑 + 时间窗口
- C：ma_support(10) AND rsi_oversold(30) — 均线支撑 + RSI 超卖

## 三、已实现功能

### 数据库

- `watch_stock.limit_up_date`：涨停日期 YYYYMMDD
- `watch_pool.trigger_target_pool_id`：买点触发后加入的目标池

### 后端

- `limit_up_service.py`：直接调用 Tushare 获取涨停股，不依赖全量同步
- `POST /api/strategy/limit-up/collect`：涨停筛选，参数 `trade_date`、`window_days`
- `GET /api/pools/{id}/stocks`：支持 `limit_up_date_from`、`limit_up_date_to` 筛选
- 监控引擎：支持多条件 AND/OR 组合，涨停相关模板自动读取 `limit_up_date`

### 前端

- 数据管理页：涨停筛选入口，无需全量同步
- 观察池：涨停日期列、涨停池按日期筛选、池编辑支持「买点触发后加入」目标池
- 池编辑：监控规则管理，可添加/删除买点规则（均线支撑、涨停板价支撑、时间窗口、黄金分割等）

---

## 四、使用流程

1. 创建「核心观察池」
2. 执行涨停筛选 → 自动创建「涨停股票观察池」及默认 MA10 规则
3. 编辑涨停池，设置「买点触发后加入」= 核心观察池
4. （可选）编辑涨停池，添加更多买点规则（如涨停板价支撑、时间窗口）
5. 同步涨停池 → 手动扫描 → 买点触发后自动加入核心池
