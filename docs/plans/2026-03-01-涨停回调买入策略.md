# 涨停回调买入策略 — 实施方案（已实施）

> 2026-03 实施完成。实现「涨停回调买入法」：每日筛选涨停股加入专用观察池并打标签，监控回踩 MA10 买点，触发后自动加入核心观察池。

---

## 一、策略逻辑与数据流

- **每日任务**：全市场日线同步 → 筛选涨停股 → 加入涨停股票观察池 → 打涨停日期标签
- **监控扫描**：扫描涨停池，ma_support(n=10) 检测回踩 MA10
- **买点触发**：创建 Alert 后，自动将股票加入配置的目标池（核心观察池）

---

## 二、已实现功能

### 数据库

- `watch_stock.limit_up_date`：涨停日期 YYYYMMDD
- `watch_pool.trigger_target_pool_id`：买点触发后加入的目标池

### 后端

- `limit_up_service.py`：涨停判断（主板 9.9%/创业板科创板 19.9%/北交所 29.9%）、排除 ST
- `POST /api/strategy/limit-up/collect`：涨停筛选，参数 `trade_date`、`window_days`
- `GET /api/pools/{id}/stocks`：支持 `limit_up_date_from`、`limit_up_date_to` 筛选
- 监控引擎：Alert 创建后根据 `trigger_target_pool_id` 自动加入目标池

### 前端

- 数据管理页：涨停筛选入口，可配置处理最近 N 个交易日
- 观察池：涨停日期列、涨停池按日期筛选、池编辑支持「买点触发后加入」目标池

---

## 三、使用流程

1. 全市场日线同步（数据管理页）
2. 创建「核心观察池」
3. 执行涨停筛选 → 自动创建「涨停股票观察池」及 MA10 监控规则
4. 编辑涨停池，设置「买点触发后加入」= 核心观察池
5. 同步涨停池 → 手动/自动扫描 → 买点触发后自动加入核心池
