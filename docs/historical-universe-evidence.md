# 历史证券池与真实证据构建

离线构建器把已冻结的逐日原始证券列表转换为可追溯 CSV，不查询当前业务主数据、不联网、不连接数据库。当前只支持普通沪市主板 A 股子集，不能直接生成全市场分母。

## 使用

```bash
cd backend
./venv/bin/python scripts/build_historical_universe.py \
  --input-package /private/source-package/input-package.json \
  --input-sha256 <审阅并保存的输入包SHA256> \
  --output-dir /private/new-history-build
```

输出目录的父目录须已存在；目标目录必须是新路径。输入先全部校验、序列化，再独占创建目录及文件。目录权限0700，文件0600；失败只清理本次仍拥有的文件，不覆盖旧输出。返回0表示构建成功，不是行情质量通过。错误返回1且不打印连接串或原始敏感错误。

输入 JSON 版本 `historical-universe-input-v1`，固定 `selection=sse_main_board_a`、`scope=security_subset`、`temporal_basis=retrospective`。主要字段：

| 字段 | 内容 |
|---|---|
| `dates` | 去重前须唯一的 YYYYMMDD 日期列表 |
| `membership_sources` | 每日期一项 `trade_date/path/sha256` |
| `basic_source` | 当前基本资料的 `path/sha256` |
| `documentation_sources` | 非空的 `id/path/sha256/url/locator` 定义原件列表 |

包与原件均绑定同一次读取字节；拒绝重复 JSON key、错误摘要、越界路径及非普通文件。SDK 原始包须为本轮已支持的 BaoStock 0.9.1 解码格式：保留原始字符串单元、完整字段/行数、成功状态、带时区观察时间及上游日期回显。原始 TCP SDK 表格结果不是完整网络帧，认证帧不保存；API 文档 URL 是字段定义来源，不能冒称该 SDK 响应的 HTTP 下载地址。

## 入池规则

成员只来自指定交易日 `query_all_stock(day)` 的原始代码及 `tradeStatus`。日期请求和上游回显必须相同；空响应、重复代码、字段/实际行数/状态不一致均拒绝。不得从当前列表回补历史缺行。

固定选择 `sh.600/601/603/605`，再检查 `query_stock_basic` 中类型为股票、IPO/退市日期与目标日相容。当前 `status=0` 不会排除退市前的历史成员；但当前退市且缺退市日期、缺 IPO、分类冲突等均不作成功。保留当日名称，不用当前名称覆盖过去。其他市场、科创板/CDR和明确非股票有排除统计；未知沪市家族不会被静默归入成功。

这只产生供应商观察到的历史候选状态。`tradeStatus=0` 的解释须结合日期级官方停复牌材料核验，不能仅由它推广为所有日期的全天停牌认证。当前基本资料也不等于完整历史分类；重组或重新上市导致日期冲突时，需要补历史证据，不能丢弃冲突行以凑控制数。

## 输出与控制证据

| 文件 | 用途 |
|---|---|
| `universe.csv` | 规范代码、证券类型、上市/交易状态及当日名称 |
| `row-lineage.jsonl` | CSV 行与原始成员/分类行、原值、摘要及行号的对应关系 |
| `build-report.json` | 每日观察到的挂牌/交易/停牌数、排除统计与来源限制 |
| `complete-index.json` | 前三文件字节数、SHA及完成说明 |

必须同时检查正常命令完成和索引内全部文件；进程被强制结束可能留下不完整的新目录。目录/文件身份检查不是同 UID 恶意微观竞争下的原子 CAS，不能宣称创建目录与首次取身份之间的所有置换都能识别；不要复用失败目录或删除其中归属不明的并发文件。

构建器不生成 `counts.csv`，观察到的行数不是独立控制总数。控制数须来自不同原件及同统计口径。例如本轮另行核验的两日沪主板 A 官方挂牌1700，扣全天停牌2/0，独立得到1698/1700；不是对构建 CSV 再数一次。最终以[既有证据清单](market-data-quality-audit.md)绑定 CSV、独立控制与原件，明确声明 `security_subset`。即使全部匹配，仍不能取得全市场资格。
