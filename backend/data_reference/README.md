# 离线审计参考数据

`sse_calendar_2026.csv` 是 2026 年连续自然日历，供 T02 只读校验使用。

- 来源：[上交所上证公告〔2025〕45号](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)，发布日期 2025-12-22，核对日期 2026-11-04。
- 交叉核对：[2026 年中秋节、国庆节休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20260915_10832273.shtml)。
- 生成规则：周六/日休市，并排除公告列出的元旦、春节、清明、劳动节、端午、中秋及国庆休市区间；调休周末仍不开市。
- 范围为 2026-01-01 至 2026-12-31。未核对临时停市或证券级停牌；不是上市、退市、全天停牌的证券分母。
- 显式通过 `--calendar-csv` 使用，不自动改变业务调度器或写入业务库。跨年使用需提供覆盖对应日期的新日历。
- CSV 的 SHA-256 被写入每次 JSON 报告。公告更新后应保存新版本，再重跑审计。
